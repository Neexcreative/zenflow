- `airplane-cabin.mp3`
- `exam-hall.mp3`
- `commuter-train.mp3`

- `nyc-morning.mp3`
- `light-rain.mp3`
- `heavy-rain.mp3`
- `thunderstorm.mp3`
- `fireplace.mp3`
- `campfire.mp3`
- `office.mp3`
- `wind.mp3`
- `white-noise.mp3`
- `pink-noise.mp3`
- `brown-noise.mp3`
- `binaural-alpha.mp3`
- `binaural-theta.mp3`
- `binaural-delta.mp3`

If a file is missing, the app will keep running and log a console warning.
